## MONSTER AI LAB — Академия монстров

Игра на Scratch 3 для курса детям 8–12 лет: питомец, тренировки, арена,
босс и управление жестами с локальным ИИ. План на 12 уроков по 45 минут,
с вариантами на 10 и 14.

- **[Скачать готовую игру с ИИ](downloads/Monster_AI_Lab_Classroom.zip)** — распаковать весь архив и открыть `START_WINDOWS.bat` (нужен Python 3.10+).
- **[Открыть проект Scratch](monster-ai-lab/web/game/Monster_AI_Lab.sb3)** — скачать файл и загрузить в Scratch 3.
- [Как запустить и как устроен ИИ](monster-ai-lab/README.md).
- [Программа занятий](monster-ai-lab/docs/COURSE_RU.md).
- [Карта блоков](monster-ai-lab/docs/BLOCKS_RU.md) и [карточки ученика](monster-ai-lab/docs/WORKSHEETS_RU.md).

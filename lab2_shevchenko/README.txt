Композиция и перегрузка операторов
Шевченко О.Н., ВИИМ21, вариант 2
Профиль: Искусственный интеллект и математическое моделирование

Состав комплекта:
- ЛР2_Шевченко_ОН_вариант_2.docx — редактируемый отчёт;
- ЛР2_Шевченко_ОН_вариант_2.pdf — отчёт с фиксированной вёрсткой;
- programs/task1_floor.py — расчёт напольного покрытия;
- programs/task2_book.py — класс Book;
- programs/task3_ensemble.py — ансамбль моделей Ensemble и Model;
- programs/task4_loss.py — класс Loss;
- programs/test_lab2.py — 15 автоматических тестов;
- assets/figure1.png ... figure10.png — иллюстрации отчёта;
- assets/task*.py.txt — полные протоколы демонстрационных запусков;
- validation.txt — результаты проверок.

Требуется Python 3.10 или новее. Сторонние библиотеки для программ и тестов
не нужны. Исходники сохранены в UTF-8.

Запуск из папки распакованного комплекта:
python3 programs/task1_floor.py
python3 programs/task2_book.py
python3 programs/task3_ensemble.py
python3 programs/task4_loss.py
На Windows команду python3 можно заменить на python.

Запуск тестов:
python3 -m unittest discover -s programs -v

Ввод чисел: десятичная точка, а не запятая.
Задание 1: все размеры в метрах. Препятствия должны находиться внутри пола
и не пересекаться. Число плиток рассчитывается по площади, без запаса
на подрезку и без учёта швов.
Задание 2: количество страниц — целое неотрицательное число. Операторы
поддерживают Book и числа. Дробный результат +, -, * отклоняется;
деление округляется стандартным round Python (половины к чётному).
Задание 3: точность в диапазоне [0, 1], время в минутах. Оптимальность
означает минимум моделей в непустом подмножестве, средняя точность которого
достигает цели. Если хотя бы одна модель достигает цели, ответ — одна
лучшая модель. Иначе цель недостижима. Прогноз точности голосующего ансамбля
невозможен по одним средним точностям без дополнительных предположений.
Задание 4: неотрицательные конечные вещественные потери. is_converging
проверяет строгое уменьшение относительно предыдущих потерь; это
индикатор одного шага, а не доказательство сходимости всей последовательности.

Группа подтверждена: ВИИМ21. Название вуза, факультет, кафедра,
преподаватель и год сохранены из присланного образца.

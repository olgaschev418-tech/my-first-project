# Первое занятие: инструкция преподавателю по минутам

**90 минут · 8–10 лет · Windows + настольный GDevelop · ученический шаблон Monster Protocol 2.1.**

Результат: ребёнок открыл свою копию, познакомился с частями героя, выбрал внешность, сохранил имя и стартовый вид в исходнике и снова открыл проект. В середине есть пять минут разминки и отдельная 15-минутная игра без компьютера.

Минута означает время от начала урока, а не длительность отдельного щелчка. Это опорный сценарий: если группе нужно больше времени, убирайте дополнительные изменения, а не перерыв. Заранее установите редактор; установка и скачивание больших архивов в 90 минут не включены.

## Что открыть до прихода детей

1. На своём ноутбуке распакуйте **Demo**, запустите START_WINDOWS.bat и оставьте готовую игру в браузере. Проверьте один бой и руку. Во время урока это окно только для показа преподавателя.
2. На каждом детском ноутбуке распакуйте **Student**, а не Demo. В Windows: Проводник → Загрузки → правой кнопкой по ZIP → «Извлечь всё / Extract All» → «Извлечь». Найдите извлечённую папку, внутри которой есть `project`, `docs` и LICENSE. Скопируйте **эту папку целиком** в `Документы/AI_GAME/Маша` (имя ребёнка своё). В итоге существует `Документы/AI_GAME/Маша/project/game.json` и рядом папка `assets`.
3. Установите настольный GDevelop с https://gdevelop.io/download . Проверьте открытие `project/game.json` и локальный предпросмотр. Для первых занятий детская камера не нужна.
4. На столе: мышь, бумага, карандаш, бумажные части монстра для игры. Напишите на бумаге путь к папке ребёнка. На экране преподавателя оставьте крупный масштаб.
5. Подготовьте папку `Документы/AI_GAME_Копии` для резервных копий. Не храните единственную работу только внутри ZIP.

**Ориентиры интерфейса:** «Менеджер проекта / Project manager» содержит Scenes и Game settings; редактор сцены показывает расставленные объекты; вкладка Events показывает правила; окно Preview — запущенную игру. Нажатия внутри Preview проверяют игру, но не добавляют события в редактор.

Ниже даны русские названия с английскими ориентирами. В разных выпусках GDevelop расположение панелей и перевод меняются. Если название отличается, ищите английское действие и описанное окно. Не переходите в создание нового проекта и не регистрируйте ребёнку аккаунт для этого урока: работаем с готовым локальным файлом.

## Три маршрута, которые пригодятся на уроке

**Открыть проект.** Запустите GDevelop → на стартовом экране «Открыть проект / Open a project» → вариант локального файла («Open a local project», «Open a project file» или «Open from your computer») → в системном окне перейдите к `Документы/AI_GAME/Маша/project` → один раз выделите `game.json` → «Открыть / Open». Если редактор уже открыт, используйте меню File → Open и выберите локальный файл. Сверьте путь, чтобы это был Student. Двойной щелчок по JSON в Проводнике может открыть текстовый редактор, поэтому основной путь — из GDevelop.

**Открыть сцену и попробовать.** В менеджере проекта раскройте «Сцены / Scenes» → дважды щёлкните `MonsterCreator` → откроется полотно сцены. Нажмите верхнюю кнопку с треугольником «Предпросмотр / Preview». Если рядом есть раскрывающееся меню, выбирайте обычный локальный запуск сцены, а не облачную/сетевую публикацию. Игра появится в отдельном окне или вкладке. Вернуться к редактированию: закрыть только окно Preview либо переключиться назад в GDevelop. При каждом контрольном запуске запускайте сцену заново, а не только обновляйте старое окно.

**Записать имя и стартовый вид.** В менеджере проекта раскройте «Настройки игры / Game settings» → «Глобальные переменные / Global variables». Найдите уже существующую строку `Name`, щёлкните её значение `Искрик`, выделите текст Ctrl+A и введите имя **без кавычек**, тип оставьте String/Строка. У `BodyVariant`, `EyesVariant`, `MouthVariant` изменяйте только числовое значение существующих строк, тип Number/Число. Нажмите «Применить / Apply», затем Ctrl+S. В редакторе значений это значения, а не формулы: сюда не пишем `GlobalVariable(...)`.

Диапазоны: BodyVariant 0–5; EyesVariant 0–7; MouthVariant 0–5. В игре надпись «2 / 6» означает индекс **1**: номер на экране на единицу больше значения переменной. Стартовый пример: имя «Плюш», тело 1, глаза 3, рот 1. Имена строк не переименовывайте и вторые одноимённые переменные не создавайте. Окно переменных объекта MonsterBody — другое окно; если в заголовке написано имя объекта, закройте его и откройте именно Global variables.

## Если что-то пошло не так

| Что видно | Что нажать или проверить |
|---|---|
| Открылся текст game.json | Закрыть текстовый просмотр. Открыть GDevelop и выбрать локальный game.json через Open a project |
| Открылась другая игра/полный рабочий бой | Сверить папку: нужен Student/project/game.json, не Demo |
| На полотне сцены нет героя | Сверить MonsterCreator. Уменьшить масштаб полотна через видимый элемент Zoom/−; не удалять объекты «для очистки» |
| Нет списка сцен | Открыть Project manager / менеджер проекта значком проекта. Ищем дерево Scenes, не файловый Проводник |
| Видны события вместо сцены | Переключиться на вкладку MonsterCreator/Scene, а не Events |
| Правая стрелка рта/кнопка лаборатории не действует | В Student это ожидаемое задание следующих занятий. Сегодня проверяем только готовые BodyNext/EyesNext |
| После нового запуска опять «Искрик» | Имя меняли только в Preview. Game settings → Global variables → существующий Name → новое значение → Apply → Ctrl+S → новый Preview |
| На экране другое тело | Переменные начинаются с 0. Проверить BodyVariant, Apply и новый запуск; не нажимать игровую кнопку «Загрузить» во время проверки стартового вида |
| Исчезли картинки | Проверить assets рядом с game.json. Восстановить всю папку из отдельной копии; не искать изображения по одному |
| Не нашли команду выбора двух глаз | Пропустить необязательное перемещение. Основной результат — имя и стартовая внешность |

## Что считать выполненным

Ребёнок показывает свою папку и открывает её проект; объясняет, где тело/глаза/рот; видит выбранное имя и сочетание после нового запуска; имеет копию всей папки. Можно закончить с помощью. Неработающие учебные кнопки остальных категорий на первом занятии не исправляются массовым копированием всего Demo.

Перемещение глаз — бонус, его можно убрать первым. Если группа отстала, преподаватель помогает записать стартовые значения и сделать копии; бумажная игра и перерыв сохраняются.

**Основание инструкции:** имена сцен, объектов, переменных и начальные возможности сверены с `student-template/game.json` версии 2.1.0. Маршруты Global variables и Select instances on scene сверены с исходниками интерфейса GDevelop. Это не отчёт о ручном прохождении конкретного выпуска Windows-редактора; до группы преподаватель один раз проходит маршрут на школьной версии и уточняет перевод кнопок.

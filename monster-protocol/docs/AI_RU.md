# Teachable Machine и камера

## Две модели, две разные цели

**Поставляемая модель карточек** — небольшая настоящая нейросеть на TensorFlow.js, обученная на синтетических цветовых примерах. Красный — ATTACK, синий — SHIELD, зелёный — HEAL, нейтральный серый — IDLE. Она удобна для проверки всего пути «изображение → модель → команда», но не распознаёт жесты и не проходила проверку на вашей физической камере.

**Модель ученика** — Image Project из Teachable Machine, обученный на его примерах. Можно начать с цветных карточек, а затем исследовать жесты. Сам сервис не превращает любую модель в надёжный датчик: фон, одежда и свет могут оказаться важнее жеста.

## Подготовка преподавателя

Откройте демонстрацию через GDevelop Preview или локальный сервер. Для камеры нужен localhost или HTTPS, разрешение браузера и свободная камера. Перед уроком проверьте на школьном ноутбуке, не использует ли её другое приложение. При работе в браузерном редакторе камера может зависеть от разрешений окна предпросмотра; настольный GDevelop/локальная игра — основной путь комплекта.

Модель загружается только по явному действию. Камера включается только кнопкой, звук не запрашивается. После закрытия панели и перехода между сценами видеодорожки останавливаются. Сохранение игры не сохраняет модель/файлы/разрешение камеры. В новой вкладке выберите модель снова.

## Обучить свою модель

1. Откройте https://teachablemachine.withgoogle.com/train/image . Выберите **Image Project → Standard image model**.
2. Создайте **ровно четыре** класса с точными именами: `ATTACK`, `SHIELD`, `HEAL`, `IDLE`. Регистр важен. Порядок классов не важен: адаптер сопоставляет по имени.
3. Договоритесь о легко различимых сигналах. Для первого раза три одноцветные карточки; для исследования жестов, например кулак/ладонь/два пальца. Не используйте лицо как обязательный признак.
4. Соберите примерно 50–100 кадров на класс, короткими сериями с разным углом/расстоянием/освещением. Для IDLE — несколько видов отсутствия команды. Классы должны быть сопоставимы по числу примеров.
5. Нажмите Train Model, дождитесь завершения. Не закрывайте вкладку во время обучения.
6. Проверьте на **новых** предъявлениях, а не только на кадрах, которые модель уже видела. Минимальный учебный протокол: 5 попыток каждого класса. Запишите предсказание и уверенность. Поменяйте фон, повторите часть попыток.
7. Если фон управляет ответом — улучшайте данные; понижение порога не лечит плохую модель.
8. **Export Model → TensorFlow.js → Download my model.** Распакуйте ZIP. Нужны `model.json`, `metadata.json` и **все файлы весов**, указанные в weightsManifest модели (часто `weights.bin`). Экспорт Keras/TFLite не подходит.
9. Для продолжения обучения используйте отдельное сохранение проекта/примеров в самом Teachable Machine, если доступно. Скачанный inference-экспорт не равен резервной копии обучающих изображений.

## Подключить

1. Перейдите в Arena. Откройте **ИИ / камера**.
2. Выберите **одновременно** model.json, metadata.json и все файлы весов. Можно выделить их в проводнике через Ctrl/Shift. Игра не отправляет их на удалённый сервер: они читаются браузером.
3. Дождитесь «Модель готова». При другом числе/именах классов получите сообщение об ошибке; исправьте экспорт, не переименовывайте классы в случайных местах вручную.
4. Нажмите **Включить камеру**, разрешите доступ. Появится зеркальное изображение для удобства позиционирования; классификатор получает исходный кадр, поэтому для асимметричных жестов внимательно повторите ориентацию обучающих примеров.
5. Панель оставьте открытой: в ней идёт распознавание, а события арены продолжают работать. Вернитесь в IDLE между командами. Здоровье, энергия и здоровье соперника видны также в строке состояния панели; при закрытии панели камера остановится.
6. Кнопка **Выключить камеру** немедленно останавливает видеодорожки. При смене сцен камера тоже остановится. В следующем бою включите её снова; модель остаётся в текущей вкладке.

В ученическом шаблоне адаптер уже есть, но нужно добавить событие из урока 11: `AICommand > 0 → Command = GlobalVariable(AICommand); AICommand = 0`. Без события показ вероятности не означает управление игрой.

## Фильтр случайных команд

- Уверенность лучшего класса не ниже **0,85**.
- Один и тот же класс удерживается **не менее 500 мс**.
- Одна удержанная команда даёт **один ход**.
- Для повторения вернитесь в IDLE/неуверенное состояние минимум на **400 мс**.
- Между командами минимум **1500 мс**.
- На сценах вне Arena команды в бой не передаются.
- Если у героя не хватает энергии, запрос модели отклоняется **теми же событиями**, что и нажатие кнопки.

Уверенность — оценка модели в рамках её классов, а не вероятность «истины вообще». Высокая уверенность на незнакомом фоне может быть ошибкой.

## Данные и сеть

В комплекте библиотеки TF.js и TM лежат локально, а встроенная модель — локальный ресурс. Игра не использует облачный API распознавания и не записывает видео. Отдельный сайт обучения Teachable Machine и школьные правила использования камеры следует проверить до урока; не переносите выводы о локальной игре на все функции внешнего сайта. Не публикуйте персональные примеры или модели детей без принятого школой порядка.

Офлайн доступна готовая игра, поставляемая модель и загрузка уже скачанной собственной модели. Первый запуск сайта обучения и его весов требует сети. При отсутствии сети проведите тестирование готовой модели и сборку кнопочной игры; обучение перенесите на занятие с проверенным доступом.

## Известные проблемы

| Проблема | Действие |
|---|---|
| Нет metadata.json | Выбрана только топология; распакуйте весь экспорт TensorFlow.js |
| Ошибка файла весов | Выберите все shards; не переименовывайте отдельные файлы после экспорта |
| Нет нужных классов | В Teachable Machine исправьте имена, переобучите/переэкспортируйте |
| Чёрный кадр/запрет | Проверьте камеру в другом приложении, разрешения, localhost/HTTPS |
| Слишком медленно | Уменьшите другие вкладки/эффекты; используйте карточки и кнопки, модель запускается в браузере ноутбука |
| Модель всё время видит один класс | Разнообразьте данные и IDLE, проверьте фон и число примеров |
| Повторная команда не идёт | Вернитесь в IDLE минимум 0,4 с, затем удержите команду 0,5 с |
| Нажатие «Включить» без модели | Сначала загрузите файлы или встроенную модель карточек |

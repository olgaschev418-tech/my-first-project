# Восемь занятий: приложения, кнопки и проверки

**Инструкция преподавателю · 8 × 90 минут · Windows · настольный GDevelop · Monster Protocol 2.1.**

Для первого занятия есть отдельный [сценарий с 90 строками по одной минуте](FIRST_LESSON_CLICKS_RU.md). Здесь — маршруты действий и сценарии остальных семи встреч с шагом до пяти минут. Каждый интервал имеет начало и конец; нажатия выполняются внутри этого времени, с паузой на повторение детьми.

Это дополнение к [основному плану](LESSONS_RU.md), а не новый курс. У детей открыт **Student/project/game.json**, Demo используется преподавателем для показа. Нужны установленный GDevelop, отдельные папки и распакованные ресурсы. До урока один раз пройдите маршрут на школьной версии: названия переводов и расположение панелей могут различаться. Английские названия ниже — ориентиры поиска, а не обещание одинакового расположения кнопок во всех выпусках.

## Какие приложения нужны

| Приложение | Когда и зачем |
|---|---|
| GDevelop, настольный редактор | Все встречи: сцены, объекты, события, глобальные переменные, сохранение проекта |
| Preview / Предпросмотр | Все встречи: запуск и проверка игры из GDevelop |
| Проводник Windows | Открытие папки, копия всей работы, перенос и итоговый ZIP |
| Бумага / паспорт | История героя, проверки, 15-минутные игры и рассказ |
| Браузер с Teachable Machine | Только необязательная расширенная ветка занятия 7 |
| Блокнот Windows | Занятие 8: простая инструкция запуска и карточка проекта |
| Ножницы Windows / Snipping Tool | Занятие 8: скриншот игры; при необходимости помогает преподаватель |

Для основных готовых жестов сайт Teachable Machine не открывается: нейросеть уже включена в шаблон. Камеру до занятия 6 детям включать не требуется.

## Карта 1. Открыть сцену и её события

1. В GDevelop откройте менеджер проекта значком проекта, если дерево скрыто.
2. Раскройте **Scenes / Сцены**.
3. Дважды нажмите имя: `MonsterCreator`, `Lab`, `Arena` или `Final`.
4. Для расположения деталей выберите вкладку сцены. Для правил — вкладку **Events / События** этой же сцены. В некоторых версиях это отдельная вкладка с именем сцены и припиской Events.
5. Сверьте название текущей сцены перед редактированием. Изменение Lab не добавляет событие в Arena.
6. В событиях раскройте группу стрелкой слева от её названия. У группы может быть длинное имя, но начало `02`, `04.1`, `04.2`, `04.3` различимо.
7. Для проверки нажмите **Preview / Предпросмотр**. Если запускается текущая сцена, проверяйте нужные глобальные стартовые значения. Для полного пути запускайте из MonsterCreator.
8. После изменения закрывайте старое Preview и запускайте новое. Сохраняйте исходник **Ctrl+S**.

## Карта 2. Скопировать событие переключателя

Используем занятие 2, исходное событие BodyNext в MonsterCreator → Events → группа **02 · Образцы событий**.

1. Найдите строку, где условие указывает объект **BodyNext**, а действие меняет **BodyVariant**.
2. Один раз нажмите на левую серую часть **всей строки события**, чтобы выделились условия и действия целиком. Если выделилась только одна ячейка условия — снимите выделение и выберите именно событие.
3. **Ctrl+C → Ctrl+V**. Должна появиться вторая целая строка. Если нет — используйте контекстное меню строки Copy / Paste. Не держите Ctrl+V: одна копия.
4. В копии дважды щёлкните условие про курсор над **BodyNext**. В поле объекта выберите существующий **MouthNext** из списка. Нажмите **OK / Apply / Применить** в диалоге условия.
5. Оставьте условия «левая кнопка отпущена» и «выполнить один раз» без изменения.
6. Дважды щёлкните действие изменения переменной. Вместо BodyVariant выберите **MouthVariant**, область **Global / Глобальная**. Оператор **=**. Поле выражения: `mod(GlobalVariable(MouthVariant)+1,6)`. Подтвердите диалог.
7. Ctrl+S → новый Preview → нажмите стрелку рта вправо. Должен изменяться рот, а тело — остаться прежним.
8. Для обратной стрелки скопируйте событие ещё раз, объект смените на **MouthPrev**, выражение — `mod(GlobalVariable(MouthVariant)+6-1,6)`.

Остальные обязательные обратные события:

| Кнопка в условии | Глобальная переменная | Выражение действия |
|---|---|---|
| BodyPrev | BodyVariant | `mod(GlobalVariable(BodyVariant)+6-1,6)` |
| EyesPrev | EyesVariant | `mod(GlobalVariable(EyesVariant)+8-1,8)` |

BodyNext и EyesNext уже работают: вторые одинаковые события для них не добавляйте. Стартовые значения и номера на экране различаются на единицу — см. первое занятие.

## Карта 3. Создать событие щелчка с нуля

Пример: Feed в Lab. Это общий маршрут для новых кнопок, смены сцены и команд боя.

1. Откройте **Lab → Events**. Нажмите **Add event / Добавить событие**, выберите обычное **Standard event / Стандартное событие**, если тип предлагается. Появилась строка с пустыми условиями и действиями.
2. Нажмите **Add condition / Добавить условие**. В поиске введите `mouse button released` или «кнопка мыши отпущена». Выберите условие **Mouse button released**, кнопка **Left / Левая**. Подтвердите.
3. В той же строке снова **Add condition** → поиск `cursor` → условие **The cursor/touch is on an object / Курсор или касание на объекте** → выберите существующий объект **Feed** → подтвердите. В списке объектов выбирайте Feed, не FeedLabel.
4. Ещё **Add condition** → поиск `trigger once` → **Trigger once while true / Выполнять один раз, пока условия истинны** → подтвердите.
5. В правой половине этой же строки **Add action / Добавить действие** → поиск `global variable` / «глобальная переменная» → изменение **числового значения глобальной переменной**. В современных версиях это общее действие изменения переменной с выбором области **Global**.
6. Выберите уже существующую **Energy**, оператор **= / установить**, выражение `min(100,GlobalVariable(Energy)+20)`. Подтвердите.
7. Для реакции нажмите ещё **Add action** в этой строке → глобальная числовая **VisualFX**, оператор =, значение **1**. Подтвердите.
8. Ctrl+S → Preview → кнопка еды. Энергия подросла, появились эффекты; выше 100 не растёт.

Условия должны стоять **в одной строке** с действиями. Не создавайте три отдельных события «мышь», «курсор», «один раз». Если не видите слово Global, проверьте область переменной до сохранения: одноимённая переменная объекта не подходит.

**Добавить сравнение переменной:** Add condition → поиск переменной / `global variable` → числовое сравнение → область Global → Energy → знак ≥ → 20. Для сценовой Phase выберите область Scene. В версиях с отдельными условиями ищите именно Scene variable / Global variable.

## Карта 4. Сменить сцену

1. Создайте строку щелчка по карте 3, но в условии курсора выберите **ToLab**.
2. В действиях **Add action** → поиск `change scene` / «сменить сцену» → **Change the scene**.
3. Выберите **Lab** из списка сцен. Если поле текстового выражения, введите **`"Lab"`** с кавычками. Не выбирайте `MonsterCreator` по привычке.
4. Подтвердите → Ctrl+S → Preview из MonsterCreator → «В лабораторию →».
5. Кнопка Creator для возврата уже подготовлена в шаблоне. Проверьте её; не добавляйте дубликат.

## Карта 5. Дом: готовые значения для действий

Каждая кнопка — отдельная строка щелчка по карте 3. Действия внутри строки добавляются по одному через Add action. **Все перечисленные ниже переменные глобальные**. Порядок действий имеет значение.

| Кнопка и дополнительное условие | Действия сверху вниз |
|---|---|
| Feed | Energy = `min(100,GlobalVariable(Energy)+20)`; VisualFX = 1 |
| Rest | Energy = 100; Health = 100; VisualFX = 3 |
| Train, Energy ≥ 20 | Energy = `GlobalVariable(Energy)-20`; Strength = `min(30,GlobalVariable(Strength)+4)`; XP = `GlobalVariable(XP)+1`; Level = `1+floor(GlobalVariable(XP)/3)`; VisualFX = 2 |
| Train, Energy < 20 | Message, тип текст = `"Нужно 20 энергии"` |
| Battle, Wins < 3 | Round = `GlobalVariable(Wins)+1`; затем EnemyHP = `40+20*GlobalVariable(Round)`; сменить сцену на `"Arena"` |
| Battle, Wins ≥ 3 | Сменить сцену на `"Final"` |
| Decor, Gold ≥ 20 и RoomStyle < 2 | Gold = `GlobalVariable(Gold)-20`; RoomStyle = `GlobalVariable(RoomStyle)+1`; VisualFX = 4 |

**Для текстовой Message:** Add action → поиск изменения строковой глобальной переменной / Change the string value of a global variable → существующая Message → оператор = → текстовое выражение `"Нужно 20 энергии"` с кавычками → Apply. В редакторе исходных значений Name кавычки не нужны; здесь поле выражения действия, поэтому нужны.

**Отказ Train** расположите выше успешного события: иначе после успешной траты последних 20 энергии нижняя проверка может тут же показать отказ. Перетаскивайте всю строку за левую часть, пока не увидите место вставки; проверьте итоговый порядок.

Train с XP/Level и улучшения дома преподаватель вправе помочь закончить. Обязательный самостоятельный навык — ребёнок выбирает правильную кнопку, область переменной и объясняет одно ограничение.

## Карта 6. Подключить подготовленный бой

До занятия 4: Game settings → Global variables → существующая **UseBattleScaffold** → значение **1** → Apply → Ctrl+S. Тип — число. В начале урока проверяет преподаватель.

1. **Arena → Events**. Раскройте **04.2 · УЧЕНИК**. Внутри есть комментарий-задание.
2. Выделите строку комментария внутри 04.2 и добавьте обычное событие **после неё на том же вложенном уровне**. Если версия предлагает Add sub-event для группы, создайте событие внутри группы через этот пункт. Сверьте отступ: событие находится между 04.1 и 04.3, внутри 04.2.
3. Условия щелчка — как карта 3, объект **Attack**. Добавьте условие **сценовая Phase = 0**.
4. Add action → изменение числовой **сценовой** переменной → существующая **Command**, оператор =, значение **1**.
5. Дублируйте всю строку: у копии объект **Shield**, Command = **2**. Ещё копия: **Heal**, Command = **3**. Phase=0 и условия щелчка сохраняются.
6. Ctrl+S → Preview через MonsterCreator → Lab → отдых → бой. Одно нажатие Attack, дождаться ответа. Затем Shield и Heal.
7. Если бой не реагирует, проверяйте UseBattleScaffold=1, сценовую область Command/Phase и порядок групп. Не переносите команды выше 04.1: там Command очищается перед ходом.

## Карта 7. Подключить команду камеры

Занятие 6. Камера уже встроена, сайт обучения открывать не требуется.

1. **Arena → Events → внутри 04.2** добавьте обычное событие. **Без условий мыши**.
2. Add condition → числовое сравнение **глобальной AICommand > 0**. Подтвердите.
3. Add condition → сравнение **сценовой Phase = 0**. Подтвердите.
4. Add action → **сценовая Command = `GlobalVariable(AICommand)`**. Подтвердите.
5. Ещё Add action → **глобальная AICommand = 0**. Подтвердите. Сначала передать, потом очистить.
6. Ctrl+S → Preview из MonsterCreator → Lab → отдых → бой → **«Включить камеру»**.
7. Если браузер/предпросмотр спрашивает разрешение камеры, нажмите **Allow / Разрешить**. При запрете найдите значок разрешений возле адреса в браузерном окне и измените разрешение; в отдельном Preview без адресной строки помогает преподаватель, используя проверенный запуск.
8. Появится маленькое окно. Кулак — атака; ладонь — щит; два пальца — лечение. Удерживать около полсекунды, затем убрать руку. Сначала дождаться ответного хода, потом показывать следующий жест.
9. Переместить окно: зажать заголовок «Управление рукой», передвинуть и отпустить. Выключить: крестик или кнопка **«Выключить камеру»**. Проверить индикатор устройства.

Если нейросеть видит руку, но бой не действует, проверяйте событие передачи команды. Если в окне ошибка доступа, сначала исправляется доступ, а не игровые формулы.

## Карта 8. Имя, оформление и финал

**Стартовое имя/внешность:** Game settings → Global variables → существующие Name и ...Variant → Apply → Ctrl+S. Имя — текст без кавычек в значении переменной, не формула. Это отдельное действие от игрового диалога имени.

**Свой текст финала:** Scenes → Final → в списке объектов дважды **FinalText** → в редакторе текстового объекта изменить содержимое поля Text / Текст → Apply / Применить → Ctrl+S. Не менять имя объекта FinalText. Применяйте только если в окне действительно редактируется текст, а не позиция экземпляра.

**Музыка/прыжок:** Game settings → Global variables → MusicVolume (например 15 вместо 25) или ReactionHeight (например 20 вместо 27) → Apply → Ctrl+S → новый Preview. Сначала записать исходное число; менять один параметр за проверку.

**Новая игра из финала:** Final → Events → щелчок Again → глобальные Wins=0, Round=1, Health=100, Energy=60, Strength=10, XP=0, Level=1 → сменить сцену `"Lab"`. Name, ...Variant, Gold, Badges, RoomStyle не сбрасывать. Кнопка Home для возврата уже подготовлена; проверить без дубликата.

## Общая памятка исправлений

- Не срабатывает кнопка: проверить объект в условии, область переменной, наличие «отпущена», не скопирована ли только часть строки.
- Варианты пустые: проверить N и индекс; формулы приведены под исходное количество изображений.
- Бой не начинается: UseBattleScaffold=1, вход Battle, командные строки внутри 04.2, сценовая Command/Phase.
- Имя после перезапуска старое: записать Name в глобальные переменные исходника, Apply, Ctrl+S, новый Preview.
- Рука видна, действия нет: AICommand должен передаваться в Command при Phase=0; закрыть раскрытые учебные настройки.

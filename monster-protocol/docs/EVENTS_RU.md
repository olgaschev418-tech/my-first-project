# Справочник событий GDevelop

Откройте ученический `game.json`, вкладку событий нужной сцены. Готовый ответ — одноимённая сцена демонстрационного проекта. В интерфейсе разных версий переводы отличаются; используйте поиск действий. Указанные ниже имена объектов/переменных совпадают с файлами.

## Как записаны примеры

`Energy` — глобальная числовая переменная. В числовом выражении пишите `GlobalVariable(Energy)`; для текста имени — `GlobalVariableString(Name)`. `Command`, `TakenTurn`, `Damage` — переменные текущей сцены; чтение `Variable(Command)`. В новых версиях редактор предлагает переменную по имени и сам подставляет правильную область. Не создавайте вторую сценовую Energy вместо существующей глобальной.

`Energy = ...` означает действие «Изменить числовую переменную», область **глобальная**, оператор `=`. Текстовые `Message` и `Name` меняются действием для текста/строки. Все строки в поле выражения заключайте в кавычки, например `"Пора попробовать щит"`.

**Щелчок Btn** — три условия одного события:

1. Левая кнопка мыши **отпущена** (не «нажата»).
2. Курсор/касание находится над объектом **Btn**.
3. **Выполнять один раз, пока условия истинны** (Trigger once).

Действия стоят ниже этих условий. Для соседнего события повторите условия с новой кнопкой. Не помещайте все кнопки под одно условие по первому объекту.

## Переменные проекта

| Имя | Старт | Назначение |
|---|---:|---|
| BodyVariant, EyesVariant, MouthVariant и остальные ...Variant | 0 | Номера анимаций частей |
| Name | Искрик | Имя героя |
| Health | 100 | Здоровье, диапазон 0–100 |
| Energy | 60 | Энергия, диапазон 0–100 |
| Strength | 10 | Урон атаки, максимум 30 |
| XP | 0 | Число успешных тренировок |
| Level | 1 | 1 + целая часть XP/3 |
| Wins | 0 | Число побеждённых соперников, до 3 |
| Round | 1 | Номер текущего соперника |
| EnemyHP | 60 | Здоровье соперника |
| AICommand | 0 | Однократная команда адаптера: 1 атака, 2 щит, 3 лечение |
| AIPanel / NamePanel | 0 | Запрос открытия готового окна адаптера |
| SaveRequest / LoadRequest | 0 | Запрос сохранения/загрузки |
| Message | строка | Подсказка игроку |

Кнопки имени/сохранения и группа 99 уже готовы. Их не надо переписывать на занятии. Сценовые Command/TakenTurn/Damage уже объявлены во всех сценах; использовать их нужно только в Arena.

## 01. Применение внешности — уже готово

**Без условий**, каждый кадр:

- анимация MonsterBody = `GlobalVariable(BodyVariant)`;
- анимация **всех** MonsterEyes = `GlobalVariable(EyesVariant)`;
- аналогично остальных частей.

Не добавляйте условие «курсор на одном глазе» в эту группу. Тогда оба экземпляра останутся синхронны. Группа 01 присутствует в каждой сцене. На арене Rival — отдельный соперник; не меняйте его событиями MonsterBody.

| Категория | Sprite | Переменная | N | Кнопки |
|---|---|---|---:|---|
| Тело | MonsterBody | BodyVariant | 6 | BodyPrev / BodyNext |
| Глаза | MonsterEyes, два экземпляра | EyesVariant | 8 | EyesPrev / EyesNext |
| Рот | MonsterMouth | MouthVariant | 6 | MouthPrev / MouthNext |
| Руки | MonsterArms | ArmsVariant | 4 | ArmsPrev / ArmsNext |
| Ноги | MonsterLegs | LegsVariant | 4 | LegsPrev / LegsNext |
| Рога | MonsterHorns | HornsVariant | 4 | HornsPrev / HornsNext |
| Нос | MonsterNose | NoseVariant | 4 | NosePrev / NoseNext |
| Уши | MonsterEars | EarsVariant | 4 | EarsPrev / EarsNext |
| Хвост | MonsterTail | TailVariant | 4 | TailPrev / TailNext |
| Крылья | MonsterWings | WingsVariant | 4 | WingsPrev / WingsNext |

Значения таблицы относятся к исходному набору. Если ребёнок добавил анимацию, N надо изменить в обоих переключателях и случайном выборе. Для сохранения новых индексов преподавателю также надо расширить проверку `limits` в адаптере (см. ниже); во время обычного редактирования проекта ограничение относится только к загрузке сохранения, не к анимациям редактора.

## 02. MonsterCreator

**Щелчок BodyNext:** BodyVariant = `mod(GlobalVariable(BodyVariant)+1,6)`.

**Щелчок BodyPrev:** BodyVariant = `mod(GlobalVariable(BodyVariant)+6-1,6)`.

**Щелчок EyesNext:** EyesVariant = `mod(GlobalVariable(EyesVariant)+1,8)`.

**Щелчок EyesPrev:** EyesVariant = `mod(GlobalVariable(EyesVariant)+8-1,8)`.

Для Mouth и остальных замените имя и N по таблице. Два события вправо (BodyNext/EyesNext) уже есть в шаблоне. `mod()` — остаток по кругу; `%` в выражениях GDevelop не поддерживается.

**Щелчок Random:** BodyVariant = `Random(5)`; EyesVariant = `Random(7)`; MouthVariant = `Random(5)`; остальные = `Random(3)`. Все действия можно добавить в одно событие.

**Щелчок ToLab:** действие «Сменить сцену» → `"Lab"`. **Creator** в остальных сценах уже возвращает в `"MonsterCreator"`.

Числа под категориями и имя уже обновляются текстовыми действиями. Для своего поля: текст = `ToString(GlobalVariable(Energy))`. Для нескольких строк используйте `NewLine()`, не буквальную последовательность `\n`.

## 03. Lab

Добавляйте отдельные события:

| Условия | Действия |
|---|---|
| Щелчок Feed | Energy = `min(100,GlobalVariable(Energy)+20)` |
| Щелчок Rest | Energy = 100; Health = 100 |
| Щелчок Train; Energy >= 20 | Energy = `GlobalVariable(Energy)-20`; Strength = `min(30,GlobalVariable(Strength)+4)`; XP = `GlobalVariable(XP)+1`; Level = `1+floor(GlobalVariable(XP)/3)` |
| Щелчок Train; Energy < 20 | Message = `"Нужно 20 энергии. Покорми монстра или отдохни."` |
| Щелчок Battle | Round = `GlobalVariable(Wins)+1`; **затем** EnemyHP = `40+20*GlobalVariable(Round)`; сменить сцену на `"Arena"` |

Отказ тренировки лучше расположить **выше** успешного события, чтобы успех с последними 20 энергии не заменялся сообщением об отказе в том же кадре. Для действий со сложной обратной связью используйте временный флаг успешного действия.

Готовое поле Stats показывает Health, Energy, Strength, Level, Wins. Не путайте текстовый объект Stats с самими переменными: менять нужно значения, а не просто рисовать другое число.

## 04. Arena — порядок обязателен

`Command`, `TakenTurn`, `Damage` ниже — **сценовые**, остальные переменные глобальные. События читаются сверху вниз.

### A. Начало каждого кадра

Без условий: Command=0, TakenTurn=0, Damage=`6+2*GlobalVariable(Round)`.

Этот сброс должен стоять до чтения кнопок/ИИ. Если разместить ниже, он сотрёт команду. TakenTurn означает «допустимый ход совершён», а не «кнопку пытались нажать».

### B. Получить одну команду

- Щелчок Attack → Command=1.
- Щелчок Shield → Command=2.
- Щелчок Heal → Command=3.
- Глобальная AICommand>0 → Command=`GlobalVariable(AICommand)`; **затем** AICommand=0.

Последнее событие добавляется на уроке 11. Так камера и кнопки используют одинаковые правила. Без AI-события камера может показывать вероятности, но не управлять боем.

### C. Выполнить допустимое действие

| Условия | Действия |
|---|---|
| Command=1 и Energy>=10 | EnemyHP=`max(0,GlobalVariable(EnemyHP)-GlobalVariable(Strength))`; Energy=`GlobalVariable(Energy)-10`; TakenTurn=1 |
| Command=1 и Energy<10 и TakenTurn=0 | Message=`"Мало энергии. Используй щит."`; здоровье соперника не менять |
| Command=2 | Energy=`min(100,GlobalVariable(Energy)+14)`; Damage=3; TakenTurn=1 |
| Command=3 и Energy>=20 | Energy=`GlobalVariable(Energy)-20`; Health=`min(100,GlobalVariable(Health)+25)`; TakenTurn=1 |
| Command=3 и Energy<20 и TakenTurn=0 | Message=`"Нужно 20 энергии для лечения."`; здоровье не менять |

Добавляйте сообщения успешных действий по желанию. При неудачном действии не устанавливайте TakenTurn=1.

### D. Ответ и переходы

1. TakenTurn=1 и EnemyHP>0 → Health=`max(0,GlobalVariable(Health)-Variable(Damage))`.
2. TakenTurn=1 и EnemyHP<=0 → Wins=`GlobalVariable(Wins)+1`.
3. EnemyHP<=0 и Wins<3 → сцена `"Lab"`.
4. Wins>=3 → сцена `"Final"`.
5. Health<=0 и EnemyHP>0 → Message=`"Отдохни и попробуй снова"`; сцена `"Lab"`.

Не делайте `Wins+1` просто каждый кадр при EnemyHP<=0. Условие TakenTurn страхует от повторного начисления. Не наносите ответный урон после смертельного удара по сопернику. Кнопка Retreat уже возвращает в Lab; при новом входе Battle здоровье текущего соперника устанавливается заново.

**Контроль:** после тренировки Strength=30. Противники имеют 60/80/100 HP, ответный урон 8/10/12. Восстановление в Lab между боями делает базовую кампанию проходимой. В демо нет скрытого босса с другим набором правил: третий соперник — финальный.

## 05. Final

Щелчок Again → Wins=0, Round=1, Health=100, Energy=60, Strength=10, XP=0, Level=1; сцена Lab. Name и все Variant не менять. Ребёнок может заменить текст поздравления и картинку.

## 99. Что делает адаптер преподавателя

- NamePanel=1 открывает окно имени, AIPanel=1 — панель модели/камеры.
- SaveRequest=1 сохраняет выбранные глобальные поля в localStorage, LoadRequest=1 проверяет и восстанавливает их. Не сохраняются текущий бой, загруженная модель, разрешение камеры и файлы исходного проекта.
- Модель выдаёт AICommand только на Arena; действия боя остаются визуальными событиями.
- Видеопоток прекращается при остановке, закрытии панели или смене сцены.
- Адаптер отключает игровую метрику GDevelop в этой игре; экспорт тестируется без внешних запросов.

Если расширяете число вариантов, измените диапазон в `limits` внутри группы 99 **во всех сценах** (или, как разработчик, в teacher/bridge.js перед генерацией новой основы). Это задача преподавателя; ребёнок может добавлять собственную графику, заменяя имеющиеся анимации, без изменения адаптера.

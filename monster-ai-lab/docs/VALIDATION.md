# Проверки сборки

Проверено в облачной среде 16 октября 2026 года: Node.js 24.19.0,
Python 3.12.14, Chromium/Playwright 1.56.1.

- `npm test`: правила выполнялись в Scratch VM, а не в их тестовой копии.
  Проверены ограничение энергии, расходы, тренировки, уровень, максимум силы,
  щит, победа над каждым из трёх соперников, финальная сцена, поражение и отдых.
  Полная кампания пройдена реальными событиями клавиатуры без подмены статов.
  Граничное поражение отдельно проверено с тестовым здоровьем 1.
- Тесты модуля команд: кулак/ладонь/два пальца, неизвестный жест, kNN на
  синтетических точках, отказ без примеров, удержание и обязательная пауза.
  Они проверяют обработку точек, а не точность нейросети на человеке.
- `npm run test:browser`: отрисовка WebGL, HTML-кнопки, щелчок по настоящему
  спрайту Scratch, смена имени и закрытие вопроса, арена, атака, щит,
  загрузка пользовательского `.sb3`, мобильная ширина 390 px.
- Браузерный тест также инициализировал настоящую MediaPipe Hands,
  загрузил локальные TFLite/WASM-файлы и обработал поток искусственной
  камеры без руки. Камера выключилась по кнопке. Не было ошибок страницы,
  неуспешных запросов ресурсов или внешних сетевых запросов.
- Этот браузерный тест повторён для файлов из **распакованного готового ZIP**,
  запущенных штатным `start_game.py`, а не только из исходной рабочей папки.
- ZIP проверен на CRC; в трёх `.sb3` проверена целостность ссылок блоков.
- `git diff --check` пройден. Существующая лабораторная работа не изменялась.

**Не проверено:** настоящая рука человека, конкретная школьная камера,
Windows/macOS и их диалоги разрешений. Это обязательная практическая проверка
преподавателя перед уроком. Работа на реальном устройстве не утверждается
на основании искусственного видеопотока.

`npm audit --omit=dev` также сообщает унаследованные предупреждения
зависимостей Scratch: hull.js (и связанные scratch-render/scratch-vm), uuid.
Автоматическое предлагаемое понижение Scratch VM до старой основной версии
не применялось. Комплект предназначен для локальной учебной работы с
известными проектами; перед публичным размещением сервиса отдельно
проверяйте актуальные исправления движка. Это не проверка безопасности
произвольных загруженных Scratch-проектов.
